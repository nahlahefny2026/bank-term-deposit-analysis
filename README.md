# 🏦 Bank Term Deposit Analysis

## 📌 Project Overview
This is an end-to-end Data Analytics project that analyzes a Portuguese bank marketing campaign to identify the key factors influencing customers to subscribe to term deposits.

The project demonstrates the complete analytics workflow using Python, SQL, and Power BI.

---

## 🎯 Objectives
- Analyze customer demographics and banking behavior.
- Identify factors affecting term deposit subscriptions.
- Build an interactive dashboard for business insights.
- Provide actionable recommendations to improve marketing campaigns.

---
